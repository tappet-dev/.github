# Contributing to Tappet projects

Thanks for helping. Each repository has its own CONTRIBUTING.md with build and test steps; start there.

- Discuss larger changes in a GitHub Discussion or issue before opening a pull request.
- Sign off your commits (`git commit -s`) to certify the [Developer Certificate of Origin](https://developercertificate.org/).
- Keep pull requests focused; include tests.
- By contributing you agree your contribution is licensed under the repository's license (Apache-2.0 unless stated otherwise).
